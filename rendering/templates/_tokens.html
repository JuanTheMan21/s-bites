{# Shared design system for every scene template. Not a composition on its own: three Jinja macros, {% import %}'d by each of the six intent templates so the video reads as one produced piece rather than six unrelated scenes (house-style.md: "same background across all scenes"). tokens_style() -- font loading + CSS custom properties + shared classes. background_markup(prefix, duration_sec) -- the #bg clip's inner HTML (the one ambient element). background_script(prefix, duration_sec) -- the GSAP lines that animate it, appended to the caller's own `tl` at the caller's chosen point. `prefix` namespaces element ids per template (e.g. "tc" for title_card) -- each composition is a standalone single-file index.html, so collision is not a runtime risk, but distinct ids make the rendered HTML readable on its own per data-attributes.md's id-hygiene note. Non-negotiable per hyperframes-core: no element below carries its animated end-state in static CSS (a CSS initial `transform` paired with a GSAP tween on the same property is a lint failure, `gsap_css_transform_conflict`) -- every from-state here is set in JS via `fromTo`, never in CSS. Revised after the first real video: the previous "Data Drift" identity (near-black + blurred purple/cyan glow blobs + a 24-particle ambient field) read as generic AI dark-mode despite trying to avoid that -- named cliches are specific instances, not the whole territory. This version is flatter and more diagrammatic: true black, two flat colors used for what they mean rather than for mood, no blur, no gradients, one restrained ambient device instead of a decorative field. Colors carry meaning, not decoration: --accent-primary marks emphasis (the point of the scene -- a headline's mark, a stat's value); --accent-secondary marks structure (diagrams, data, code, markers -- things that organize information rather than assert it). #} {% macro tokens_style(palette=none) %} {% endmacro %} {% macro background_markup(prefix, duration_sec) %}
{% endmacro %} {% macro background_script(prefix, duration_sec) %} // The one ambient device: a hairline frame that fades in with the scene, then breathes slowly // for the rest of the duration. This is load-bearing, not decorative -- `hyperframes check`'s // frozen-sweep guard fails a composition with no genuine animated property across its full // length, and every template's own entrance tweens finish in the first second or two. Genuine // GSAP property tween on `opacity`, never a manual `onUpdate` proxy: HyperFrames seeks this // timeline with `suppressEvents` (D15's `seek(t, true)` convention), which skips onUpdate // callbacks entirely but still applies a tracked property's own interpolated value -- caught // live once already on a manual onUpdate particle drift that rendered fine in preview and did // nothing under this project's actual capture/render/check pipeline. // // 0.22 floor / 0.32 peak, never lower: `hyperframes check`'s frozen-sweep guard treats opacity // below 0.2 as invisible for its own liveness fingerprint (D89.3) -- the range here stays // comfortably clear of that floor at every point in the cycle, not just at its peak, the same // proven-safe 0.22 baseline the particle field this replaced already used for the same reason. tl.fromTo("#{{ prefix }}-frame", { opacity: 0 }, { opacity: 0.22, duration: 1.0, ease: "power2.out" }, 0); (function () { var totalDur = {{ duration_sec }}; var half = 1.75; var start = 1.0; // Duration-aware repeat, never a fixed count: a hardcoded repeat covers only // duration * (repeat + 1) seconds and then freezes for whatever's left of the segment -- // the exact bug a fixed `repeat: 1` produced once already on this project's idle-bob motion. var reps = Math.max(1, Math.ceil((totalDur - start) / half)) + 2; tl.to("#{{ prefix }}-frame", { opacity: 0.32, duration: half, ease: "sine.inOut", yoyo: true, repeat: reps }, start); })(); {% endmacro %}
